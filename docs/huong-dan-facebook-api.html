📚 Học tập & Luyện code

Lấy bài viết Facebook Group bằng Console

Hướng dẫn từng bước — không cần cài thêm gì, chạy thẳng trong trình duyệt

5 bước · ~10 phút
⚠️ Lưu ý: Hướng dẫn này chỉ dành cho mục đích học tập. Chỉ dùng với account của chính bạn, không scrape số lượng lớn liên tục. Việc sử dụng sai mục đích vi phạm ToS của Facebook.
1
Mở Facebook và vào trang Group
▼

Đăng nhập Facebook và truy cập vào Group bạn muốn lấy bài viết. URL sẽ có dạng:

URL
https://www.facebook.com/groups/727550767618720/
💡 Group ID chính là dãy số trong URL. Lưu lại con số này để dùng ở bước sau.
🌐
Ví dụ URL: facebook.com/groups/727550767618720
2
Mở DevTools Console
▼

Mở Developer Tools của trình duyệt theo một trong các cách sau:

  • ⌨️ Nhấn F12 (hoặc Ctrl + Shift + I trên Windows/Linux, Cmd + Option + I trên Mac)
  • 🖱️ Click chuột phải vào trang → chọn "Inspect" hoặc "Kiểm tra"
  • 📌 Sau khi DevTools mở, click vào tab "Console"
⚠️ Nếu thấy cảnh báo "Don't paste code you don't trust" — gõ allow pasting rồi Enter để bỏ qua.
3
Lấy Token tự động Tự động
▼

Copy đoạn code bên dưới, dán vào Console và nhấn Enter. Script sẽ tự động lấy tất cả token cần thiết:

JavaScript — Console 
// Lấy các token cần thiết từ Facebook
const FB_DTSG = require("DTSGInitialData").token;
const LSD     = require("LSD").token;
const USER_ID  = require("CurrentUserInitialData").USER_ID;
const GROUP_ID = window.location.pathname.match(/groups\/(\d+)/)?.[1];

console.log("✅ Token lấy được:");
console.table({ FB_DTSG, LSD, USER_ID, GROUP_ID });

Kết quả mong đợi trong Console:

✅ Token lấy được:
┌──────────┬────────────────────────────────┐
│ FB_DTSG │ "NAfxkNrIvn0Cuaj-ANPbt9Ag..." │
│ LSD │ "y85zJnQfclmxr4hN0FpSmw" │
│ USER_ID │ "100087403596874" │
│ GROUP_ID │ "727550767618720" │
└──────────┴────────────────────────────────┘
ℹ️ Nếu GROUP_ID hiển thị null → bạn chưa vào đúng trang Group. Quay lại bước 1.
4
Gọi API lấy bài viết Chính
▼

Đây là đoạn code chính — gọi API GraphQL của Facebook để lấy 20 bài viết mới nhất. Dán tiếp vào Console:

JavaScript — Console 
// ============================================
// GỌI API LẤY BÀI VIẾT FACEBOOK GROUP
// ============================================

async function getGroupPosts(count = 20, cursor = null) {

  // 1. Lấy token
  const fb_dtsg   = require("DTSGInitialData").token;
  const lsd       = require("LSD").token;
  const group_id  = window.location.pathname.match(/groups\/(\d+)/)?.[1];

  if (!group_id) {
    console.error("❌ Không tìm thấy Group ID. Hãy vào trang Group trước!");
    return;
  }

  // 2. Chuẩn bị variables
  const variables = {
    count,
    feedLocation: "GROUP",
    feedType: "DISCUSSION",
    id: group_id,
    sortingSetting: "RECENT_ACTIVITY",
    feedbackSource: 0,
    filterTopicId: null,
    focusCommentID: null,
    privacySelectorRenderLocation: "COMET_STREAM",
    renderLocation: "group",
    scale: 1,
    stream_initial_count: 3,
    useDefaultActor: false,
  };
  if (cursor) variables.cursor = cursor;

  // 3. Gửi request
  const body = new URLSearchParams({
    fb_dtsg,
    lsd,
    fb_api_caller_class: "RelayModern",
    fb_api_req_friendly_name: "GroupsCometFeedRegularStoriesPaginationQuery",
    variables: JSON.stringify(variables),
    doc_id: "27224875563850383",
    server_timestamps: "true",
  });

  const res = await fetch("https://www.facebook.com/api/graphql/", {
    method: "POST",
    headers: { "Content-Type": "application/x-www-form-urlencoded" },
    body,
    credentials: "include", // gửi cookie tự động
  });

  const text = await res.text();

  // 4. Parse kết quả
  const posts = [];
  let nextCursor = null;
  let hasNextPage = false;

  for (const line of text.trim().split("\n")) {
    try {
      const data = JSON.parse(line);

      // Lấy danh sách bài
      const edges = data?.data?.node?.group_feed?.edges ?? [];
      for (const edge of edges) {
        const n = edge.node;
        posts.push({
          post_id     : n.post_id,
          author      : n.actors?.[0]?.name ?? "Ẩn danh",
          message     : n.message?.text ?? "",
          url         : n.url,
          created_at  : new Date(n.creation_time * 1000).toLocaleString("vi-VN"),
          likes       : n.feedback?.reaction_count?.count ?? 0,
          comments    : n.feedback?.comment_rendering_instance?.comments?.total_count ?? 0,
          has_image   : (n.attachments?.length ?? 0) > 0,
        });
      }

      // Lấy cursor trang tiếp
      const pageInfo = data?.data?.node?.group_feed?.page_info;
      if (pageInfo) {
        nextCursor  = pageInfo.end_cursor;
        hasNextPage = pageInfo.has_next_page;
      }

    } catch {}
  }

  return { posts, nextCursor, hasNextPage };
}

// ====== CHẠY ======
console.log("⏳ Đang lấy bài viết...");
const result = await getGroupPosts(20);

console.log(`✅ Lấy được ${result.posts.length} bài viết`);
console.log(`📄 Còn trang tiếp: ${result.hasNextPage}`);
console.table(result.posts);
✅ Sau khi chạy, bảng kết quả sẽ hiện ra ngay trong Console với đầy đủ thông tin từng bài viết.
5
Xem kết quả và Export Bonus
▼

Sau khi có kết quả, bạn có thể xem chi tiết hoặc export ra JSON/CSV:

Xem chi tiết 1 bài
JavaScript 
// Xem nội dung đầy đủ bài đầu tiên
console.log(result.posts[0].message);

// Xem tất cả bài
result.posts.forEach((p, i) => {
  console.log(`\n--- Bài ${i+1} ---`);
  console.log("👤", p.author);
  console.log("🕐", p.created_at);
  console.log("❤️ ", p.likes, "| 💬", p.comments);
  console.log("🔗", p.url);
  console.log(p.message.slice(0, 150) + "...");
});
Export ra JSON
JavaScript 
// Tải file JSON về máy
const json = JSON.stringify(result.posts, null, 2);
const blob = new Blob([json], { type: "application/json" });
const url  = URL.createObjectURL(blob);
const a    = document.createElement("a");
a.href     = url;
a.download = "fb_posts.json";
a.click();
Load trang tiếp (pagination)
JavaScript 
// Lấy thêm 20 bài tiếp theo
if (result.hasNextPage) {
  const page2 = await getGroupPosts(20, result.nextCursor);
  console.log("📄 Trang 2:", page2.posts.length, "bài");
  console.table(page2.posts);
}

Xử lý lỗi thường gặp
▼
LỗiNguyên nhânCách fix
GROUP_ID = null Chưa vào trang Group Truy cập URL group trước rồi chạy lại
posts = [] (rỗng) doc_id bị cũ Vào DevTools → Network → tìm request graphql → lấy doc_id mới
Lỗi require is not defined Không phải trang Facebook Phải chạy console trên trang facebook.com
Response 200 nhưng data rỗng Token hết hạn Reload trang Facebook, lấy lại token
